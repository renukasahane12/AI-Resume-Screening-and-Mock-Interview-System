# 🤖 AI Resume Screening & Mock Interview System

An AI-powered web application that analyzes resumes, calculates an ATS score, generates interview questions, and provides AI-based interview feedback using the Gemini API.

---

## 📌 Features

- 📄 Upload Resume (PDF)
- 📊 ATS Score Calculation
- ✅ Resume Keyword Matching
- ❌ Missing Skills Detection
- 🤖 AI Resume Analysis
- 🎤 AI Mock Interview
- 💬 AI Interview Feedback
- 📝 Interview Question Generation
- 🌐 Simple Flask Web Interface

---

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Resume-Screening-and-Mock-Interview-System.git
```

2. Open the project folder

```bash
cd AI-Resume-Screening-and-Mock-Interview-System
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Add your Gemini API key in `app.py`

```python
GEMINI_API_KEY = "YOUR_API_KEY"
```

5. Run the application

```bash
python app.py
```

6. Open your browser

```
http://127.0.0.1:5000
```

## 📷 Application Workflow

1. Upload a resume (PDF).
2. Enter a job description.
3. View ATS score.
4. Review AI resume analysis.
5. Generate interview questions.
6. Start the mock interview.
7. Receive AI feedback for each answer.
